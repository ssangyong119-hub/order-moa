# 오더모아 HTML 화면 프로토타입

## 목적

오더모아 1차 MVP의 **핵심 화면 흐름을 브라우저에서 눈으로 확인**하기 위한 정적 데모입니다.
완성 앱이 아니라, **"사장님이 발주를 붙여넣으면 품목별 합산표가 나온다"** 는 핵심 가치를 검증하는 것이 목표입니다.

## 디자인

`D:\Downloads\DESIGN-claude.md`의 톤을 참고했습니다 — warm cream 캔버스(`#faf9f5`), coral 포인트(`#cc785c`), ink 텍스트(`#141413`), hairline 보더, 8px/12px 라운드, 헤드라인은 serif. 마케팅 랜딩이 아니라 **실제 업무용 ERP 화면**을 목표로, 큰 히어로·장식 없이 "오늘 할 일" 중심으로 구성했습니다. 상태는 **정상(초록) / 수량 확인(노랑) / 미매칭(빨강) / 단가 미등록(앰버)** 배지로 구분하고, 거래명세서는 실제 명세서처럼 정돈했습니다. 외부 폰트/CDN 없이 시스템 폰트만 사용합니다.

## 실행 방법

- `order-moa-demo.html` 파일을 **브라우저로 열기**(더블클릭 또는 브라우저에 끌어다 놓기).
- 설치·서버·빌드 불필요. 인터넷 연결도 필요 없습니다.

## 이건 실제 앱이 아닙니다

- **정적 데모**입니다. HTML/CSS/JavaScript 한 파일로만 동작합니다.
- **DB / Supabase / API 연결 없음.** 모든 데이터는 브라우저 메모리(자바스크립트 배열/객체)에서만 동작하며, 새로고침하면 초기화됩니다.
- 외부 패키지/CDN 없음.
- 샘플 데이터는 모두 **가명**이며 개인정보/실거래처명/전화·사업자번호를 포함하지 않습니다.

## 구현된 화면 흐름

1. **대시보드** — "오늘 할 일" 중심. 가장 큰 버튼은 [발주 붙여넣기], [샘플 데이터 시작].
2. **샘플 데이터 시작** — 가명 거래처/품목/별칭/단가/발주 예시 적재.
3. **발주 붙여넣기** — 거래처 선택 + 원문 붙여넣기(샘플 예시 선택 가능) + 원문 저장/삭제 안내.
4. **파싱 결과 확인/수정** — 라인별 품목·수량·단위·단가·금액·상태. 미매칭(빨강)/수량 확인(노랑)/단가 미등록(0원 경고). 미매칭·수량 확인이 있으면 [주문 확정] 비활성.
5. **품목별 합산표** — 품목·단위·총수량·관련 거래처 수. CSV 내보내기.
6. **거래명세서 미리보기** — 거래처·품목·수량·단가·금액·공급가 합계. VAT 없음. 인쇄 가능(PDF 미구현).

> 로그인/회사 생성 화면은 만들지 않았습니다. 상단에 "데모 회사: 오더모아 샘플상사"로 표시하고 핵심 흐름을 바로 보여줍니다.

## 데모 시나리오 (추천)

1. [샘플 데이터 시작] → [샘플 데이터 불러오기]
2. [발주 붙여넣기] → 예시 **① 정형(가람식당)** 선택 → [파싱] → 전부 정상 → [주문 확정]
3. [품목별 합산표] 확인
4. (경고 흐름) 발주 붙여넣기 → 예시 **③ 수량 불확실** 또는 **⑤ 미매칭** → [파싱] → 확정 차단 확인 → 수량 입력/품목 선택으로 해결
5. [거래명세서 미리보기] → 공급가 합계 확인 → [인쇄]
