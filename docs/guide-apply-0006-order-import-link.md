# 발주 원문 저장 켜기 — Supabase에 0006 적용하기 (비개발자용)

작성일: 2026-07-08 (Claude)
소요 시간: 약 2분
대상 파일: `web/supabase/migrations/0006_order_import_link.sql`

## 이게 뭔가요?

주문 확정 시 붙여넣은 **카톡/문자 발주 원문**을 DB에 함께 저장하고, 나중에 지울 수 있게 하는 기능(W09)입니다.
발주 원문을 보관하는 `ordermoa_order_imports` 테이블은 이미 있지만, **"이 원문이 어느 주문 것인지" 연결(order_id)이 없어서** 주문별로 보여주고 지울 수가 없었습니다.
이 작업은 그 연결 컬럼(`order_id`)과 안전 검사(같은 회사 주문만 연결)를 추가합니다.

- 기존 데이터는 **하나도 지워지지 않습니다** — 컬럼과 안전 검사만 늘어납니다.
- 데이터 잠금(RLS) 규칙은 기존 그대로입니다.

> ⚠️ **중요**: 최신 앱 코드는 이 연결이 있다고 가정합니다.
> - **적용 전**: DB(로그인) 모드에서 주문 확정은 정상 동작하지만, **발주 원문은 저장되지 않습니다**(주문 상세에서 "저장된 발주 원문이 없습니다"로 표시 — 오류는 아님).
> - **적용 후**: 발주 원문 저장·보기·삭제가 모두 동작합니다.
> - 데모 모드는 이 작업과 무관하게 항상 동작합니다.
>
> 이 SQL은 다시 실행해도 안전합니다(`add column if not exists`). 두 번 실행해도 `Success. No rows returned`면 정상.

## 순서

1. **Supabase 접속** — 브라우저에서 https://supabase.com → 로그인 → `yangsan-inventory` 프로젝트 클릭.

2. **SQL Editor 열기** — 왼쪽 메뉴 **SQL Editor** → **New query**.

3. **파일 내용 복사** — 아래 파일을 메모장으로 열고 **전체 선택(Ctrl+A) → 복사(Ctrl+C)**:
   ```
   D:\Documents\ERP-1\web\supabase\migrations\0006_order_import_link.sql
   ```

4. **붙여넣고 실행** — SQL Editor에 붙여넣기(Ctrl+V) → **Run**(또는 Ctrl+Enter).

5. **성공 확인** — `Success. No rows returned` 이면 끝.

## 잘 됐는지 확인 (1분)

1. 왼쪽 **Table Editor** → `ordermoa_order_imports` 클릭.
2. 컬럼에 `order_id` 가 새로 보이면 성공.
3. 앱에서 로그인 → 발주 붙여넣기 → 주문 확정 → 주문 목록 → **보기** → "발주 원문 보기"가 나오면 성공.
4. 원문 삭제 → F5 새로고침 → 삭제 상태 유지, 주문/금액/명세서는 그대로면 완료.
