## 1. 왜 이 테스트를 하나

8b(주문 DB 저장)로 넘어가기 전에, **"이 앱이 실제 현장 발주 말투를 알아먹는가"** 를 먼저 확인한다.
샘플 데이터(콩나물 2박스)는 이미 통과했지만, 실제 품목은 이렇게 생겼다:

> `세척숙주(3.5kg) [BOX]` · `건취나물 [1kg 국산]` · `계란 [특]` · `배추(5입) [망]`

품목명에 규격·원산지·괄호가 붙고, 현장 호칭은 "숙주", "취나물", "알배추"처럼 줄어든다.
이 간극을 파서가 얼마나 흡수하는지 확인하고, 안 되는 것은 **별칭 등록으로 해결되는지 / 파서 개선이 필요한지** 나눈다.

## 2. 준비물

- 로컬 앱 실행: `cd web` → `npm run dev` → `http://localhost:3000`
- 로그인 없이 **데모 모드**로 해도 되고(env 제거), 로그인 상태여도 된다 — 이번 테스트는 파싱 화면까지만 쓰므로 DB에 영향 없다.
- 이번 테스트에는 앱의 기본 샘플 대신 **엑셀의 "품목·별칭 후보" 시트**를 보면서, 품목/별칭/단가를 화면에서 직접 등록하거나(빠른 확인) 다음 단계에서 테스트 코드로 자동화한다.
  - 주의: 현재 데모 화면은 앱 내 품목 등록 UI가 없으므로, **1차 확인은 "발주문장 테스트" 시트의 문장을 붙여넣고 파싱 결과만 관찰**해도 충분하다(샘플 품목과 겹치는 문장은 매칭되고, 실품목 전용 문장은 미매칭으로 뜨는 게 정상).

## 3. 테스트 방법 (단계별)

1. 엑셀 `발주문장 테스트` 시트를 연다. 18개 문장이 있다.
2. 앱에서 **[발주 붙여넣기]** → 거래처 아무거나 선택 → 문장 하나를 붙여넣고 **[파싱]**.
3. 파싱 결과 화면에서 다음을 본다:
   - 품목이 **의도한 품목으로** 잡혔는가? (엉뚱한 품목이면 "오매칭")
   - 수량·단위가 맞는가?
   - 상태 배지: 정상(초록) / 후보 확인(앰버) / 수량 확인(노랑) / 미매칭(빨강) / 단가 미등록(앰버)
4. 엑셀의 `실제 결과` 열에 **O(예상대로) / X(예상과 다름)** 를 적고, 다르면 `메모`에 한 줄.
5. 미매칭이 뜬 라인은 **품목 지정 → [별칭 등록]** 으로 해결되는지도 확인해 메모.
6. 18개가 끝나면 `테스트 요약` 시트에 O/X 개수를 적는다.

> 성공 기준(제안): **예상대로 동작 ≥ 15/18**. 후보_확인(t03)은 오매칭을 막기 위한 안전장치이므로, 후보 배지와 확정 차단이 보이면 O로 친다.

## 4. 예상 결과 분포 (18건)

| 예상 상태 | 건수 | 의미 |
|---|---|---|
| 성공 | 12 | 매칭+수량+단위 모두 정상 (t11·t12·t14 개선 반영) |
| 후보_확인 | 1 | 여러 품목 후보가 잡혀 사용자가 최종 선택해야 함(t03) |
| 별칭_필요 | 2 | 미매칭 → 별칭 등록으로 해결되는 유형 |
| 수량_확인 | 2 | "조금", "두 판" — 사람이 확정(의도된 안전장치) |
| 단위_확인 | 0 | 키로/장 케이스는 개선 2차에서 성공으로 전환 |

| 오매칭_위험 | 0 | t03은 개선 3차에서 후보_확인으로 전환 |

## 5. 실데이터에서 확인된 파서 함정 (개선 후보, 코드는 아직 안 고침)

1. **규격 숫자 vs 수량 숫자** — ~~"청양고추 1kg 2봉"에서 첫 숫자 1을 수량으로 오인~~ → **개선 1차 적용 완료(2026-07-02)**: 수량단위 결합 숫자(2봉) > 단독 숫자 > 측정단위(kg/g/L/ml) 결합 숫자 순으로 채택. "감자 3kg"처럼 측정단위 숫자만 있으면 그대로 수량.
2. **동일 토큰 다중 품목** — 적용 완료(2026-07-06): "숙주"가 `세척숙주(3.5kg)[BOX]`와 `숙주[1kg 수입]` 둘 다에 포함되면 후보 목록을 보여주고, 사용자가 품목을 한 번 선택하기 전까지 확정 차단.
3. **1글자 품목(무)** — 정확일치만 허용이라 "무 2개"는 미매칭. 오매칭 방지를 위한 의도된 제한이므로 별칭 등록으로 해결(안내 강화).
4. **단위 사전 부족** — 적용 완료(2026-07-06): 키로/킬로 계열은 kg로 표준화, 장/마리/모/봉지 인식.
5. 표기 표준 — `품목명(규격) [단위]` 혼재는 1차 유지(스펙 §10.3), 가이드만.
