## 3. 용어 통일 기준 (문서 QA용)

정의의 단일 소스는 **재설계 문서(`order-moa-system-redesign-2026-07-11.md`) §2 용어표**로 하고, 다른 문서는 용어를 재정의하지 않고 참조한다.

| 용어 | 통일 정의(요약) |
|---|---|
| 주문 확정(기존 용어) | 기존 단일 경로의 저장 행위. W23 이후 "최종 확정"으로 수렴(기존 화면 문구는 단계 구현 전까지 유지) |
| 수량 확인 | 품목·수량·단위까지 사람이 확인한 상태. 합산·매입처 발주에 사용 가능, 명세서 불가 |
| 가격 대기 | 수량 확인됐으나 판매단가가 최종 결정되지 않은 주문 상태 |
| 가격 마감 | 매입가·제안값을 보고 판매단가를 확정하는 행위(사람이 결정) |
| 최종 확정 | 판매단가가 스냅샷으로 고정되는 순간. 이후 수정은 정정 절차만 |
| 매입처 발주 | 우리가 매입처에 보낼 구매 문장 생성·복사(수량 기반, 가격 불필요) |
| 거래명세서 | 우리→거래처 판매 서류. **최종 확정된 주문만** 발행(가격 대기는 불가 또는 워터마크 미리보기) |
| 기본 출고단가 | products.base_sale_price. 거래처별 단가 없을 때의 **제안값**(자동 확정 아님) |
| 예상 마진 | 표시 시점 참고 계산. 저장하지 않음(불변) |
| OCR | 입력 어댑터 후보. 완전 자동 제외 유지, 형식 고정 사진 행 추출 실험은 검증 게이트 뒤 |

## 4. 스냅샷 원칙 재정의 (충돌 예방 핵심)

- 기존 문구: "`order_items.unit_price`는 **확정 시점** 스냅샷."
- W23 이후 문구: "`order_items.unit_price`는 **판매단가가 최종 확정되는 시점**(빠른 경로=주문 확정 순간, 가격 나중 경로=가격 마감 순간)의 스냅샷이며, 그 후 불변. 과거 주문·명세서는 customer_prices/base_sale_price/매입가 변경으로 재계산하지 않는다."
- 이 재정의는 기존 확정 주문의 의미를 바꾸지 않는다(기존 주문은 전부 "최종 확정" 상태로 해석).
