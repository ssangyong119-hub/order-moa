## 1. 응답 개요

응답 수:

- 총 5건

응답 업종:

- 농산물
- 농산물/기타
- 공산품/축산/농산/수산
- 공산/농산
- 식자재/공산품/수산물/일화용품 등

주요 거래처:

- 일반 음식점: 3건
- 프랜차이즈 매장: 3건
- 마트/슈퍼: 2건
- 기타: 2건
- 학교/기관/급식처: 1건
- 카페/베이커리: 1건

거래처 수:

- 10곳 미만: 2건
- 10~30곳: 2건
- 100곳 이상: 1건

하루 주문 건수:

- 5~10건: 1건
- 11~30건: 2건
- 50건 이상: 2건

## 2. 주문 접수 방식

거래처 주문 접수 방식:

- 카카오톡 개인 채팅: 4건
- 문자: 4건
- 카카오톡 단체 채팅방: 3건
- 전화: 2건
- ERP/주문앱: 1건
- 기타: 1건

카카오톡 주문을 다시 ERP/엑셀/장부에 옮겨 적는 일:

- 매일 있다: 3건
- 거의 없다: 1건
- 해당 없음: 1건

주문 정리에서 번거로운 부분:

- 여러 카톡방/전화 주문을 한곳에 모으기: 3건
- 거래명세서 만들기: 3건
- 거래처별 단가 확인하기: 2건
- 수량, 단위, 박스/개수 변환 확인하기: 2건
- 직원에게 주문 내용을 전달하기: 2건
- 특별히 불편한 점 없음: 2건
- 상품명/별칭/오타 매칭: 1건
- 단가 변경 후 이전 단가로 잘못 계산하는 일: 1건
- 배송/출고 리스트 만들기: 1건
- 오늘 전체 물량을 상품별로 합산하기: 1건

상품별 물량 합산:

- 매우 번거롭다: 1건
- 조금 번거롭다: 2건
- 현재 방식으로 충분하다: 1건
- 해당 없음: 1건

해석:

- 카카오톡/문자 기반 주문은 확실히 많다.
- 응답 5건 중 3건이 카카오톡 주문을 매일 다시 입력한다고 답했다.
- 발주 자동 취합은 MVP 핵심 가설로 유지한다.

## 3. 현재 ERP/관리 방식

현재 업무 관리:

- ERP 프로그램/앱: 5건
- 세무사/직원이 대부분 정리: 3건
- 카카오톡만 사용: 2건
- 엑셀: 1건
- 기타: 1건

사용 프로그램:

- 이카운트: 3건
- 직접 개발 사용: 1건
- 미응답: 1건

월 비용:

- 무료: 1건
- 3만~5만 원: 3건
- 10만 원 이상: 1건

현재 방식의 아쉬운 점:

- 카카오톡 주문과 연결이 약하다: 2건
- 직원과 공유하기 어렵다: 2건
- 크게 불편한 점 없다: 2건
- 재고 관리가 불편하다: 1건
- 비용이 부담된다: 1건
- 세금계산서 발행 금액 관리가 불편하다: 1건

거래처별 단가:

- 단가 변경이 자주 있다: 3건
- 거래처마다 단가가 많이 다르다: 1건
- 대체로 같은 단가를 사용한다: 1건

해석:

- 응답자 전원이 ERP를 사용 중이다.
- 이카운트 사용자가 3건으로 많다.
- 오더모아는 "ERP를 처음 쓰게 하는 제품"보다 "기존 ERP보다 현장 주문/단가/공유가 쉬운 업종 특화 ERP"로 잡는 편이 좋다.
- 단가 변경/단가 불투명성은 강한 문제 신호다.

## 4. 거래명세서, 미수금, 세금계산서

거래명세서 작성/전달:

- ERP에서 자동 생성: 5건
- 카카오톡/문자로 내용만 전달: 2건
- 엑셀로 직접 작성: 1건
- 종이/수기 작성: 1건
- 기타: 1건

미수금/입금 확인:

- ERP에서 관리: 4건
- 통장 내역을 보고 직접 확인: 3건
- 엑셀로 관리: 1건
- 세무사/직원이 확인: 1건
- 기타: 1건

세금계산서 발행 금액 조정:

- 자주 있다: 1건
- 가끔 있다: 2건
- 거의 없다: 2건

세금계산서 부족/초과 자동 확인 필요도:

- 매우 필요하다: 2건
- 있으면 좋다: 1건
- 현재 방식으로 충분하다: 2건

세무/월말 정산 자유응답:

- 계산서 금액 맞추기가 쉽지 않다.
- 세무업무 자체가 불편하다.
- 과세/면세 따로 계산하는 번거로움이 있다.
- 세무기장비가 아깝다.
- 없음.

해석:

- 거래명세서 자체는 이미 ERP로 해결되는 경우가 많다.
- 그러나 미수금/입금 확인은 ERP와 통장 확인이 병행된다.
- 세금계산서/세무 기능은 전체 사용자에게 보편적 필수는 아니지만, 일부에게는 강한 수요가 있다.
- MVP 1순위는 발주 취합, 2순위는 미수금/입금, 3순위는 세금계산서/세무 정산으로 두는 것이 좋다.

## 5. 필요 기능과 지불 의사

가장 도움이 될 기능:

- 카카오톡 주문 내용을 주문서로 자동 정리: 3건
- 거래명세서 자동 생성: 2건
- 미수금/입금 확인: 2건
- 월말 세무기장 자료 정리: 2건
- 오래된 미수금 알림: 2건
- 거래처별 상품 단가 자동 적용: 1건
- 단가 변경 이력 확인: 1건
- 세금계산서 발행 금액 부족/초과 확인: 1건
- 모바일에서 빠른 주문 확인: 1건
- 직원과 주문/배송 상황 공유: 1건
- 재고 관리: 1건

월 사용료 지불 의사:

- 월 1만 원 이하: 1건
- 월 1만~3만 원: 1건
- 월 3만~5만 원: 1건
- 월 5만~10만 원: 1건
- 기능을 봐야 판단 가능: 1건

돈을 내고라도 해결하고 싶은 문제:

- 입금확인 및 미수금 정리
- 품목별 마진 계산기
- 식자재 유통 업무 시스템이 타 업종보다 뒤처져 있음
- 발주 시스템
- 계산서 발행금액 표시
- 카톡 및 문자 발주 자동 취합

추가 자유응답:

- 믿을 수 없는 단가
- 불투명한 단가
- 카톡 및 문자 발주 자동 취합

해석:

- 가장 강한 제품 문장은 "카톡/문자 발주 자동 취합"이다.
- 단가 문제는 단순 단가표보다 "믿을 수 없는 단가/불투명한 단가/마진 계산"까지 연결해야 한다.
- 미수금/입금 확인은 발주 취합 다음으로 수익화 가능성이 있다.

## 6. 후속 인터뷰

후속 질문 가능:

- 카카오톡으로 간단히 가능: 2건
- 가능하다: 1건
- 전화 통화도 가능: 1건
- 미응답: 1건

해석:

- 다음 단계는 전체 설문을 더 돌리기보다, 응답자 2~3명을 골라 10분 인터뷰하는 것이 좋다.

개인정보 보호:

- 연락처는 이 문서에 기록하지 않는다.
- 후속 연락은 원본 엑셀에서만 확인한다.

## 7. 오더모아 제품 방향 반영

이번 설문 기준 MVP 우선순위:

1. 카톡/문자 발주 자동 취합
2. 거래처별 주문표 생성
3. 품목별 총 발주/출고 합산
4. 거래처별 단가 관리 및 단가 변경 이력
5. 미수금/입금 확인
6. 거래명세서 생성
7. 월말 세무기장/세금계산서 금액 확인

기존 MVP와 비교:

- 기존 MVP의 거래처/품목/단가/발주/합산/거래명세서 방향은 유지한다.
- 다만 거래명세서 생성보다 "카톡/문자 발주 취합"을 더 앞에 두어야 한다.
- 단가 관리는 단순 저장이 아니라 변경 이력, 마진, 매입가/판매가 비교까지 확장해야 한다.
- 미수금/입금 확인은 2단계 기능으로 너무 늦추지 말고 빠르게 화면 설계에 포함한다.

## 8. 다음 인터뷰 질문

후속 인터뷰에서 물어볼 질문:

1. 카톡/문자 발주를 하루에 몇 개 채팅방에서 받는가?
2. 발주 내용을 ERP에 다시 입력하는 데 하루 몇 분 정도 걸리는가?
3. 사진 발주는 얼마나 자주 오는가?
4. 가장 자주 틀리는 것은 품목명, 수량, 단위, 단가 중 무엇인가?
5. 도매상에 발주할 때 품목별 총량은 어떻게 계산하는가?
6. 거래처별 단가가 바뀌면 어디에 기록하고 누가 확인하는가?
7. 매입가가 바뀌었는데 판매가를 못 바꿔 손해 본 적이 있는가?
8. 미수금/입금 확인은 하루 또는 월말에 어떻게 하는가?
9. 세금계산서 발행 금액 부족/초과를 어떤 방식으로 맞추는가?
10. 지금 ERP를 끊고 새 프로그램으로 바꾸려면 어떤 기능이 반드시 있어야 하는가?

## 9. 결론

설문 표본은 5건으로 작지만, 제품 방향을 버릴 정도는 아니며 오히려 핵심 가설을 보강한다.

가장 강한 신호:

> 카톡 및 문자 발주 자동 취합

두 번째 신호:

> 단가 변경, 단가 불투명성, 마진 계산

세 번째 신호:

> 미수금/입금 확인과 세금계산서/월말 정산

따라서 오더모아는 단순 거래명세서 앱보다, 발주 취합을 시작점으로 단가/마진/미수금/정산까지 이어지는 중간 납품업자 전용 ERP로 가는 것이 맞다.
