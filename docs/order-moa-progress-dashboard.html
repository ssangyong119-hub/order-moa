오더모아 (Order-Moa) 진행현황

전체 ERP 대체가 아니라, 도소매/식당납품 사장님용 좁은 웹 ERP MVP. 핵심 가치: 카톡/문자 발주를 붙여넣으면 파싱, 합산표, 매입처별 발주 문장, 거래명세서까지 이어지는 것.

한눈에 보기

지금은 “붙여넣기 데모”를 넘어, 품목 검색과 매입처별 발주 문장까지 들어간 상태입니다. 다음 큰 작업은 샘플로 박혀 있는 매입처/품목/단가를 사용자가 직접 고치는 기준정보 관리 화면입니다.

  • 카톡/문자 발주 원문 붙여넣기
  • 품목/수량/단가 정제(파싱+수정)
  • 품목 검색으로 빠른 수정
  • 거래처별 판매가 자동 적용
  • 예상 마진 참고값 표시
  • 주문 확정
  • 품목별 합산표
  • 매입처별 발주 문장 분리/복사
  • 주문 목록(판매조회형)
  • 거래명세서 미리보기/브라우저 인쇄

완료/구현됨

  • 개발용 데모 진입Supabase 이메일 rate limit이 걸려도 버튼으로 앱 화면을 볼 수 있음
  • 좌측 사이드바형 업무 화면홈/대시보드/발주/조회/기준정보/자금/설정 메뉴 구조로 정리
  • 샘플 발주 16개짧은 예시뿐 아니라 6줄/10줄 긴 발주도 선택 가능
  • 파서 단위 사전 확장키로, 장, 모, 봉지 등 현장 표현을 더 잘 인식
  • 다중 품목 후보 확인숙주처럼 여러 품목에 걸리는 경우 '후보 확인'으로 막고 사용자가 선택
  • 품목 검색 선택 UI수세미/김치처럼 검색하면 관련 품목, 단위, 단가, 매입처를 보고 선택
  • 기본 매입처별 발주 문장야채/두부콩나물/공산품 등 샘플 매입처별로 발주 문장을 분리
  • 합산표 체크박스보낼 품목을 체크하면 매입처별 발주 문장에 들어가고, 복사 가능
  • 매입처 발주 체크 기본 비움합산표가 열려도 처음엔 발주문장이 비어 있고, 사용자가 체크한 품목만 매입처별 문장에 들어감
  • 거래명세서 모양 보정품목이 적어도 빈행을 채워 명세서 형태가 무너지지 않음
  • 8b 저장 기반 코드DB 모드에서 샘플 기준정보 시드와 주문 저장 흐름 구현. 실사용 실측은 남음
