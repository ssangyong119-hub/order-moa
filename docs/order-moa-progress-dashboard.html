기준일 2026-07-02 · 브랜치 codex/integrate-mvp-docs-web · 운영용 관리표
이 프로젝트는 전체 ERP를 대체하는 게 아니라, 도소매/식당납품 사장님이 카톡/문자 발주를 붙여넣으면 합산표·매입처 발주 문장·거래명세서까지 바로 나오게 하는 좁은 웹 ERP MVP입니다.
핵심 흐름 — 카톡/문자 발주 원문 → 품목/수량/단가 정제 → 거래처별 판매가 적용 → 예상 마진(참고값) → 주문 확정 → 품목별 합산표 → 매입처 발주 문장 복사 → 주문 목록 → 거래명세서 미리보기/인쇄

지금 어디까지 왔나 (한 줄 요약)

앱 화면 흐름(단위 6·7)과 로그인·회사·데이터 잠금 기반(단위 8a)까지 끝났고, 실제 Supabase에서 로그인 → 회사 '히든식품' 생성 → 앱 진입 성공, 이어서 잠금 검증(8a-검증) 전부 통과했습니다: 다른 회사 사용자에겐 히든식품 데이터가 0/0/0으로 안 보이고, 몰래 넣기(위조 insert)도 DB가 막았습니다.
비유: 8a는 문패와 출입문을 단 단계 — 문이 잠기고, 옆집 열쇠로 우리 집이 안 열리는 것까지 확인했습니다. 다음 8b가 실제 주문 장부를 저장하는 단계라, 지금은 주문을 확정해도 새로고침하면 사라집니다(의도된 데모 상태).
