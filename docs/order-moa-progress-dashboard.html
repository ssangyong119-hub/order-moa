전체 ERP 대체가 아니라, 도소매/식당납품 사장님용 좁은 웹 ERP MVP. 핵심 가치: 카톡/문자 발주를 붙여넣으면 파싱, 합산표, 매입처별 발주 문장, 거래명세서까지 이어지는 것.

핵심 흐름 (이 순서가 제품의 전부)

카톡/문자 발주 원문 붙여넣기 → 품목/수량/단가 정제(파싱+수정) → 품목 검색·신규 품목 즉석 등록 → 거래처별 판매가 자동 적용 → 예상 마진 참고값 표시 → 주문 확정 (단가 스냅샷 저장) → 품목별 합산표 → 매입처별 발주 문장 분리/복사 → 주문 목록(판매조회형) → 거래명세서 미리보기/브라우저 인쇄

완료된 기반 (여기까지 왔습니다)

  • 앱 뼈대 + 문서 설계 (단위 1~5) — Next.js 앱 틀, DB 장부 양식/잠금 규칙 설계, 화면 설계, 정적 데모, 이카운트 벤치마크 반영
  • 핵심 흐름 데모 (단위 6~7) — 붙여넣기→파싱→확정→합산표→명세서가 화면에서 돌아감. 복사용 발주 문장 포함
  • 로그인·회사·데이터 잠금 (8a) — 로그인, 회사 만들기, 회사별 데이터 격리를 실제로 검증 완료 (다른 회사 데이터는 0건 조회, 위조 저장은 DB가 거부)
  • 주문 DB 저장 실측 (8b/W08) — 확정한 주문이 DB에 저장되고, 새로고침 후 주문 목록에 남는 것을 실제 로그인 상태에서 확인 완료
  • 파서 현장 보강 — 키로/장/모 단위, 규격 숫자 구분(청양고추 1kg 2봉), 숙주처럼 여러 후보가 잡히면 사용자 확인, 실제 발주 예시 테스트
  • 업무 화면 정리 — 좌측 사이드바 메뉴, 품목 검색, 미매칭 품목 즉석 등록, 매입처별 발주 문장(체크한 품목만), 명세서 빈행/인쇄 보정
  • 헌장/로드맵 고정 (W01) — 앞으로의 발전 방향을 담은 헌장 4종 문서를 확정하고 커밋(fc59baa)
