# 오더모아 샘플 데이터 정의서

작성일: 2026-06-29
작성 주체: Claude (단위 3 — 샘플 데이터)
근거 문서: `docs/mvp-validation-strategy.md`, `docs/function-specification.md`, `docs/screen-specification.md`(S4), `docs/db-schema-definition.md`, `docs/mvp-acceptance-checklist.md`

> 본 문서는 시연/검증용 **가명 샘플 데이터**를 정의한다. **개인정보·실거래처명·전화/사업자/계좌번호는 포함하지 않는다.** 모든 값은 테스트용 임의값이다. 코드·SQL·마이그레이션은 포함하지 않는다.

---

## 1. 문서 목적

- 실제 거래처 데이터가 없어도 **주요 흐름(붙여넣기 → 파싱 → 합산표 → 명세서)을 시연**할 수 있게 한다.
- 지인/실제 업체 데이터 없이도 데모가 가능해야 영업을 시작할 수 있다.
- 영업/검증용 MVP에서 **샘플 데이터가 1순위**인 이유: 시연 즉시성이 없으면 "이거 편한데?"를 보여줄 수 없다(`mvp-validation-strategy.md` §8).

---

## 2. 샘플 데이터 원칙

- **개인정보 없음** / **실거래처명 없음**
- **전화번호/사업자번호/계좌번호 없음**
- 기준 업종: **식자재 납품업**
- 구성: **거래처 · 품목 · 별칭 · 단가 · 발주 예시** 포함
- **회사 생성 후 적재**(screen-spec §14 Q1 확정, `company_id` 기준 저장)
- **샘플 데이터임을 UI에서 표시**(screen-spec §14 Q5)
- **초기화 가능**(다시 만들기 / 비우기)
- 단가 미등록 품목을 일부 남겨 **0원 + 경고**를 테스트(§14 Q2)

### 6.1 샘플 기준 매입단가 + 예상 마진 (참고값, 일부만)

## 7. 샘플 발주 원문 (10건)

붙여넣기 테스트용. 각 예시: 거래처 / 원문 / 기대 파싱 / 테스트 목적.

### 예시 1 — 정형 (가람식당)
```
콩나물 2박스
두부 3판
미나리 5단
```
- 기대: 콩나물 2박스(8,000→16,000), 두부 3판(2,500→7,500), 미나리 5단(3,500→17,500) 전부 matched.
- 목적: **기본 정형 파싱 + 단가 자동 적용**.

### 예시 2 — 별칭 (으뜸반찬)
```
콩 1박스
두부판 2
양파 1
```
- 기대: 콩→콩나물(7,500), 두부판→두부(2,300), 양파→깐양파(11,000) 별칭 매칭.
- 목적: **별칭 매칭**.

### 예시 3 — 수량 불확실 (늘봄분식)
```
어묵 세 박스
떡국떡 조금
대파 큰거로
```
- 기대: 어묵 매칭+수량 "세"(불확실), 떡국떡 "조금"(불확실), 대파 "큰거로"(불확실) → **노랑 경고, 확정 차단**.
- 목적: **수량 불확실 → 확정 불가**.

### 예시 4 — 단가 미등록 포함 (가람식당)
```
콩나물 1박스
양배추 2통
```
- 기대: 콩나물 matched(8,000), 양배추 matched지만 **단가 미등록 → 0원 + 경고**.
- 목적: **단가 미등록 0원 경고**.

### 예시 5 — 미매칭 포함 (행복마트)
```
위생장갑 2박스
랩 3개
```
- 기대: 위생장갑 matched(4,500), **'랩' 미매칭(빨강) → 확정 차단**.
- 목적: **미매칭 → 확정 불가 / 별칭 등록 유도**.

### 예시 6 — 한 줄 다품목 (한빛카페)
```
계란 2판, 키친타월 1박스, 식용유 1통
```
- 기대: 쉼표 분리 → 계란(6,800), 키친타월(9,000), 식용유(5,500) 3라인.
- 목적: **한 줄 다품목(쉼표) 분리**.

### 예시 7 — 정형 다수 (으뜸반찬)
```
무 5개
부추 3단
깐양파 1
두부 4판
```
- 기대: 무(1,500), 부추(3,000), 깐양파(11,000), 두부(2,300) 매칭.
- 목적: **합산표 물량 확보**.

### 예시 8 — 비정형 (가람식당)
```
두부 세개랑 미나리 5단, 대파도 2단 부탁해요
```
- 기대: 두부 "세개"(불확실), 미나리 5단, 대파 2단 → 일부 불확실.
- 목적: **비정형 문장 + 수량 불확실 혼합**.

### 예시 9 — 별칭+미매칭 혼합 (늘봄분식)
```
팽이 5봉
새송이 3팩
단무지 2개
```
- 기대: 팽이→팽이버섯, 새송이→새송이버섯 매칭(단가 미등록 0원), **단무지 미매칭**.
- 목적: **별칭 + 미매칭 혼합 처리**.

### 예시 10 — 공산품 정형 (행복마트)
```
식탁보 1BOX
위생장갑 3박스
키친타월 2박스
```
- 기대: 식탁보(19,500), 위생장갑(4,500×3), 키친타월(8,500×2) 매칭.
- 목적: **공산품/거래명세서 미리보기(공급가 합계, VAT 없음)**.

## 8. 샘플 시연 시나리오

```
1) 회사 생성
2) [샘플 데이터 시작] → 가명 거래처/품목/별칭/단가/발주 예시 적재
3) 대시보드 진입 (오늘 할 일)
4) [발주 붙여넣기] → 거래처 선택(예: 가람식당) → 예시 1 붙여넣기 → [파싱]
5) 파싱 결과 확인 (전부 matched) → [주문 확정]
6) (예시 5/3 으로 미매칭·수량 불확실 확정 차단도 시연)
7) [품목별 합산표] → "오늘 총 콩나물 3박스, 두부 7판..." 확인
8) [거래명세서 미리보기] → 공급가 합계 확인 → 인쇄(데스크톱)
```

> 시연 핵심: 4→5→7 (붙여넣기 → 확인 → 합산표)에서 "편한데?"가 나와야 한다.

## 9. 체크리스트 반영 항목 (`mvp-acceptance-checklist.md` 연결)

샘플 데이터로 검증할 항목:

- [ ] 샘플 데이터로 첫 화면/주요 흐름 시연 가능(§2 기능)
- [ ] 샘플에 거래처·품목·별칭·단가·발주 예시 포함(§2)
- [ ] 샘플에 개인정보/실거래처명 없음(§2)
- [ ] 거래처별 단가 자동 적용(예시 1, 콩나물 거래처별 상이)
- [ ] 미매칭 품목 확정 차단(예시 5 '랩', 예시 9 '단무지')
- [ ] 수량 불확실 라인 확정 차단(예시 3, 8)
- [ ] 단가 미등록 0원 + 경고(예시 4 양배추)
- [ ] 예상 마진 표시(§6.1, 콩나물·두부 등 매입단가 있는 품목)
- [ ] 매입단가 없는 품목은 마진 미표시 `-`(§6.1, 숙주·양배추)
- [ ] 품목별 합산표 생성(예시 1·7 합산)
- [ ] 거래명세서 미리보기 공급가 합계·VAT 없음(예시 10)
- [ ] 샘플 데이터 초기화 가능

## 10. 실제 ERP 품목 패턴에서 일반화한 샘플 설계 원칙

> 근거: 실사용 ERP 판매조회 엑셀/거래명세서 캡처에서 관찰한 **구조·패턴만** 일반화했다. 실거래처명·실단가·민감정보는 옮기지 않는다. 아래 값은 모두 가명·테스트용 패턴 예시다.

### 10.1 관찰된 품목 표기 패턴 (일반화)

실제 ERP 품목은 보통 **품목명 + 규격(용량/중량/포장)** 이 한 칸에 붙어 있고, 단위가 다양하다.

- 패턴: `품목명 [규격]` 예) `깐양파 [10kg]`, `식용유 [18L]`, `종이컵 [1000입]`, `위생장갑 [100매×20]`
- 같은 품목이라도 **규격이 다르면 단가·발주 단위가 달라진다**(예: 식용유 1.8L vs 18L).
- 현장에서는 규격을 생략하고 품목명만 말하는 경우가 많다(예: "양파 1" → 깐양파 10kg).

### 10.2 단위 사전 (파싱 단위 후보)

발주문에 자주 나오는 단위. 파싱 시 단위 후보 사전으로 사용한다.

| 단위 | 예시 품목 |
|---|---|
| 박스 / BOX | 콩나물, 깻잎, 오이, 어묵, 공산품 |
| kg | 감자, 당근, 마늘, 상추, 떡국떡 |
| EA / 개 | 무, 애호박, 양배추(통) |
| 봉 | 팽이버섯 |
| 단 | 미나리, 대파, 부추, 시금치 |
| 판 | 두부, 계란 |
| 팩 | 새송이버섯, 느타리버섯 |
| 망 | 양파(망 포장), 마늘(망) |
| 통 | 양배추, 식용유 |
| 포기 | 배추 |
| L / mL | 식용유, 소스류 |
| 입/매 | 종이컵(입), 위생장갑(매) |

> 1차 파싱은 위 단위 사전 + 품목 `base_unit` 매칭으로 단위 후보를 잡고, 불확실하면 사용자 확인(노랑)으로 넘긴다.

### 10.3 품목명/규격 분리 필요성 (1차 단순안)

- **1차 단순안**: 품목명에 규격을 포함해 한 필드(`products.name`)로 둔다. 예) `깐양파 [10kg]`. `base_unit`은 발주 단위(예: `박스`/`망`/`통`).
- **2차 후보**: `products.spec`(규격) 컬럼 분리 + 규격별 단가. 같은 품목의 규격 변형이 많아지면 분리한다. (1차에는 넣지 않음 — YAGNI)
- 판단 기준: 사장님이 규격을 입으로 구분해 부르면(예: "큰 식용유/작은 식용유") 분리 가치가 생긴다. 검증 후 결정.

### 10.4 별칭 패턴 보강 (파싱 매칭)

현장 호칭은 줄임말·구어·규격 생략이 많다. 별칭은 이를 흡수한다.

| 별칭 패턴 | → 품목(예) |
|---|---|
| 줄임말 | 콩→콩나물, 새송이→새송이버섯, 팽이→팽이버섯, 깐양→깐양파 |
| 규격 생략 | 양파→깐양파[10kg], 식용유→식용유[18L] |
| 포장 표현 | 콩박스→콩나물, 계란판→계란, 두부판→두부 |
| 구어/혼용 | 숙주나물→숙주, 장갑→위생장갑, 키친타올→키친타월 |
| 오타 흡수(후보) | 키친타올/키친타월, 종이컵/종이컾 |

> 별칭은 `unique(company_id, alias)` — 회사 내 한 별칭은 한 품목에만. 충돌 시 경고/차단(F5).

### 10.5 수량 표현 패턴 (파싱 후보)

| 분류 | 예시 | 처리 |
|---|---|---|
| 아라비아 숫자 | "콩나물 2박스", "두부 3판" | 정상 매칭(초록) |
| 숫자만(단위 생략) | "양파 1", "두부판 2" | 수량 OK, 단위는 `base_unit` 추정 |
| 한글 수사 | "어묵 세 박스", "두부 세개" | **불확실(노랑)** — 사용자 확정 |
| 모호 표현 | "떡국떡 조금", "대파 큰거로", "양파 좀 많이" | **불확실(노랑)** — 사용자 확정 |
| 한 줄 다품목 | "계란 2판, 키친타월 1박스" | 쉼표 분리 후 라인별 처리 |
| 군말 섞임 | "두부 세개랑 미나리 5단, 대파도 2단 부탁해요" | 품목/수량 토막 추출 + 일부 불확실 |

### 10.6 확장 후보 품목 (일반식당 자주 발주, 가명·패턴 예시)

기존 30개 샘플(§4)에 더해, 일반식당/식자재 납품에서 자주 보이는 품목 패턴. **1차 샘플 확장 후보**이며 실데이터가 아니다.

| 품목(규격 포함 예) | 기본단위 | 비고 |
|---|---|---|
| 깐마늘 [1kg] | 팩 | 다진마늘과 구분 |
| 다진마늘 [1kg] | 팩 | |
| 대파 [흙대파] | 단 | 규격 변형 예 |
| 쪽파 | 단 | |
| 청경채 | 박스 | |
| 느타리버섯 [1kg] | 박스 | 팩/박스 규격 차이 |
| 콩나물 [4kg] | 박스 | 규격별 단가 차이 예 |
| 식용유 [18L] | 통 | 대용량 |
| 식용유 [1.8L] | 개 | 소용량(규격 분리 필요성 예시) |
| 간장 [15L] | 통 | 공산품/소스 |
| 고춧가루 [1kg] | 봉 | |
| 종이컵 [1000입] | 박스 | 입 단위 |
| 위생장갑 [100매] | 박스 | 매 단위 |
| 호일 [30cm] | 개 | 규격 표기 |
| 랩 [30cm] | 개 | (현재 미매칭 테스트용 '랩'과 연계) |

> '랩'은 §7 예시 5에서 미매칭 테스트로 쓰인다. 확장 시 별칭/품목으로 등록하면 매칭되도록 설계해, **"미매칭 → 별칭 등록 → 재매칭"** 시연이 가능하다.
